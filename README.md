# Euro4All Simulator

Εκπαιδευτική web εφαρμογή (PWA) για το **ψηφιακό ευρώ**, φτιαγμένη για ηλικιωμένους, πρόσφυγες/μετανάστες και κατοίκους μικρών νησιών. Πρωτότυπο για το **ERUA iDeaThon 2026** (πρόταση EURO4ALL, Πανεπιστήμιο Αιγαίου).

> Εκπαιδευτική προσομοίωση. Δεν χρησιμοποιεί αληθινά χρήματα και δεν είναι προϊόν της ΕΚΤ. Το ψηφιακό ευρώ δεν κυκλοφορεί ακόμα.

## Τι κάνει

| Ενότητα | Τι περιέχει |
|---|---|
| **Μάθε** | 6 μαθήματα του ενός λεπτού, με ανάγνωση από φωνή (Web Speech) και 3 μεγέθη γραμμάτων |
| **Δοκίμασε** | Πορτοφόλι με 100 € παιχνιδιού. Αγορές σε λαϊκή, καφενείο, πρακτορείο πλοίων και φαρμακείο. Το καφενείο δείχνει επίτηδες λάθος ποσό, για να μάθει ο χρήστης να ελέγχει πριν πληρώσει |
| **Offline πληρωμή** | Από κινητό σε κινητό με QR, και τα δύο σε λειτουργία πτήσης. Κάθε πληρωμή είναι ένα token με ψηφιακή υπογραφή ECDSA P-256 (WebCrypto), με έλεγχο διπλής δαπάνης |
| **Επίδειξη σε μία οθόνη** | Η Μαρία δίνει 5 € στον Γιώργο, βήμα-βήμα. Είναι η εφεδρεία αν δεν δουλέψει η κάμερα στο pitch |
| **Προστατέψου** | 8 μηνύματα (SMS, κλήση, email, Viber, επιστολή): «Απάτη ή ασφαλές;» με εξήγηση |
| **Πρεσβευτής** | Ο φοιτητής ανοίγει συνάντηση και οι συμμετέχοντες μπαίνουν με QR. Η ροή είναι: συγκατάθεση → 3 ερωτήσεις πριν → άσκηση → 3 ερωτήσεις μετά |
| **Παρατηρητήριο** | Ανώνυμα αποτελέσματα πριν/μετά, βελτίωση %, αναγνώριση απάτης, κατανομή ανά ηλικία, φύλο, γλώσσα και περιοχή. Εξαγωγή CSV |

**Φιλικό για ηλικιωμένους:**
- Στην πρώτη χρήση η εφαρμογή ρωτά τρία πράγματα: γλώσσα, μέγεθος γραμμάτων (3 μεγέθη, με δείγμα) και αν θέλει ο χρήστης να του διαβάζει τα κείμενα.
- **Φωνή:** με το κουμπί «Φωνή» κάθε σελίδα διαβάζεται αυτόματα, πιο αργά από το κανονικό.
- **Απλή αρχική:** τρία μεγάλα αριθμημένα βήματα (1 Μάθε, 2 Δοκίμασε, 3 Προστατέψου), με την πρόοδο του χρήστη. Τα εργαλεία για εκπαιδευτές είναι χωριστά, πιο κάτω.
- **«Τι κάνω εδώ;»** σε κάθε οθόνη: μία πρόταση βοήθειας, που διαβάζεται και δυνατά.
- **«Δεν ξέρω»** στις απάτες: επαινεί τον χρήστη που σταματά να σκεφτεί και του λέει να ρωτήσει κάποιον που εμπιστεύεται.
- Πάντα ορατά κουμπιά **Πίσω** και **Αρχική**, κουμπιά τουλάχιστον 60px, πιο σκούρα γράμματα για καλύτερη αντίθεση, μηνύματα που μένουν περισσότερη ώρα στην οθόνη και ευγενικές διατυπώσεις («Δεν πειράζει!»).
- Επιβεβαίωση πριν από ενέργειες που σβήνουν δεδομένα, «Μπράβο» στο τέλος κάθε μαθήματος με κουμπί «Επόμενο μάθημα», δόνηση στο κινητό σε σωστό ή λάθος.

**Γλώσσες:** ελληνικά, αγγλικά, αραβικά (RTL), φαρσί (RTL) και ουκρανικά. Οι μεταφράσεις AR/FA/UK είναι πρόχειρες και πρέπει να τις ελέγξουν φυσικοί ομιλητές ή διαπολιτισμικοί μεσολαβητές.

**Χωρίς internet:** μετά την πρώτη επίσκεψη, η εφαρμογή δουλεύει χωρίς σύνδεση (service worker). Αν συνδέσεις κοινή βάση, οι απαντήσεις που δόθηκαν offline στέλνονται αυτόματα όταν επιστρέψει το σήμα.

## Τοπική εκτέλεση

```bash
cd euro4all
python3 -m http.server 8000
# άνοιξε http://localhost:8000
```

Η κάμερα και η ψηφιακή υπογραφή θέλουν `https` ή `localhost`.

## Δημοσίευση στο GitHub Pages (δωρεάν, με https)

1. Φτιάξε νέο repository, π.χ. `euro4all`, στον λογαριασμό σου.
2. Ανέβασε **όλα** τα αρχεία του φακέλου, με αυτή τη δομή, στη ρίζα του repo.
3. Πήγαινε Settings → Pages → Source: *Deploy from a branch* → `main` / `(root)` → Save.
4. Σε 1–2 λεπτά η εφαρμογή θα είναι στο `https://<χρήστης>.github.io/euro4all/`.

Όταν υπάρχει internet, τα κινητά φορτώνουν πάντα την πιο πρόσφατη έκδοση. Χωρίς internet ανοίγουν την τελευταία που έχουν αποθηκευμένη. Αν προσθέσεις νέο αρχείο, βάλ' το και στη λίστα `SHELL` του `sw.js`.

## Ζωντανό Παρατηρητήριο από πολλά κινητά (προαιρετικό, Supabase)

Αν δεν το ρυθμίσεις, κάθε συσκευή κρατά τις δικές της απαντήσεις. Αυτό αρκεί όταν οι συμμετέχοντες απαντούν σειρά-σειρά στο tablet του πρεσβευτή. Για να ενώνονται οι απαντήσεις από τα κινητά όλων (π.χ. όταν οι κριτές σκανάρουν το QR στο pitch):

1. Φτιάξε δωρεάν project στο https://supabase.com.
2. Στο SQL Editor τρέξε:

```sql
create table public.e4a_responses (
  pid text not null,
  phase text not null check (phase in ('pre','post')),
  session text, q1 smallint, q2 smallint, q3 smallint,
  age smallint, gender smallint, lang text, venue smallint, place smallint,
  scam_c smallint, scam_t smallint, ts bigint, sample boolean default false,
  primary key (pid, phase)
);
alter table public.e4a_responses enable row level security;
create policy "anon insert" on public.e4a_responses for insert to anon with check (true);
create policy "anon read"   on public.e4a_responses for select to anon using (true);
grant select, insert on public.e4a_responses to anon;
```

3. Από Project Settings → API Keys πάρε το **Publishable key** (`sb_publishable_…`) και το **Project URL**, και βάλ' τα στο `js/config.js`. Μπορείς να το αλλάξεις και κατευθείαν στο GitHub, με το μολυβάκι στο αρχείο. **Ποτέ** το secret key.

Τα δεδομένα είναι ανώνυμα: δεν περιέχουν όνομα, τηλέφωνο ή άλλο αναγνωριστικό. Το anon key είναι από τη φύση του δημόσιο. Για παραγωγική χρήση μετά τον πιλότο χρειάζεται έλεγχος πρόσβασης (Supabase Auth) και πολιτική διατήρησης δεδομένων.

## Σενάριο demo για το pitch (περίπου 3 λεπτά)

1. **Αρχική** σε κινητό με μεγάλα γράμματα. Γύρνα σε αραβικά για να φανεί η γραφή από δεξιά προς αριστερά και μετά πίσω σε ελληνικά.
2. **Καφενείο:** ο κατάλογος γράφει 2,00 €, το ταμείο 20,00 €. Πάτα Άκυρο και εμφανίζεται «Μπράβο». Εδώ το μήνυμα είναι: «μαθαίνουμε να ελέγχουμε το ποσό».
3. **Δύο κινητά σε λειτουργία πτήσης.** Στο Α: Δίνω 5 € και εμφανίζεται το QR. Στο Β: Παίρνω → κάμερα → «Πήρες 5 €» και «Η ψηφιακή υπογραφή είναι έγκυρη». Σκάναρε ξανά τον ίδιο κωδικό και εμφανίζεται ότι έχει ήδη χρησιμοποιηθεί (προστασία από διπλή δαπάνη).
4. **Πρεσβευτής:** δείξε το QR της συνάντησης στην οθόνη. Οι κριτές το σκανάρουν και απαντούν σε περίπου 90 δευτερόλεπτα. Μετά άνοιξε το **Παρατηρητήριο** για να δουν τα αποτελέσματά τους.
5. Κλείσε με τα αληθινά νούμερα από το μίνι-πιλοτικό.

**Εφεδρείες:** η «Επίδειξη σε μία οθόνη» και ένα βίντεο του demo γραμμένο από πριν. Δοκίμασε τη λειτουργία πτήσης την προηγούμενη μέρα.

> Το «Φόρτωσε δείγμα για επίδειξη» στο Παρατηρητήριο βάζει **ψεύτικα** δεδομένα, με ετικέτα «Δείγμα επίδειξης». Μην τα παρουσιάσεις ως αποτελέσματα. Χρησιμοποίησε μόνο πραγματικά δεδομένα πιλοτικού.

## Μίνι-πιλοτικό πριν τον τελικό

- 10–15 άτομα (ΚΑΠΗ, ΣΔΕ, ενήλικες εκπαιδευόμενοι), με ενημέρωση και προφορική συγκατάθεση. Η εφαρμογή ζητά επίσης συγκατάθεση στην αρχή.
- Πρεσβευτής → Άνοιξε συνάντηση → «Μπες από αυτή τη συσκευή» για κάθε συμμετέχοντα.
- Παρατηρητήριο → Αντιγραφή CSV, για ανάλυση και για την πολιτική πρόταση (policy brief).

## Τι είναι προσομοίωση

- Τα tokens υπογράφονται με κλειδί που φτιάχνεται τοπικά σε κάθε συσκευή. Η υπογραφή αποδεικνύει ότι ο κωδικός δεν αλλοιώθηκε, όχι ότι τον εξέδωσε κεντρική τράπεζα.
- Ο έλεγχος διπλής δαπάνης γίνεται στη συσκευή του παραλήπτη.
- Στο πραγματικό ψηφιακό ευρώ αυτά θα τα κάνει ασφαλές υλικό μέσα στο κινητό (secure element), με κανόνες της ΕΚΤ.

## Περιεχόμενο και πηγές (Νοέμβριος 2026)

Το περιεχόμενο βασίζεται στην πρόταση κανονισμού της Ευρωπαϊκής Επιτροπής και σε υλικό της ΕΚΤ:

- πιλοτικό το β΄ εξάμηνο του 2027 και πιθανή έκδοση από το 2029, εφόσον ψηφιστεί ο νόμος·
- offline πληρωμές με ιδιωτικότητα κοντά σε αυτή των μετρητών·
- υποχρέωση υποστήριξης από κοντά για ηλικιωμένους και άτομα με αναπηρία·
- δωρεάν βασικές υπηρεσίες για ιδιώτες·
- προειδοποιήσεις της ΕΚΤ για ψεύτικα «πιλοτικά προγράμματα».

Όλο το περιεχόμενο βρίσκεται στο `js/content.js` και **πρέπει να ενημερώνεται** όταν οριστικοποιηθεί ο κανονισμός.

## Αρχεία

```
index.html            η σελίδα
css/app.css           εμφάνιση (φωτεινό/σκοτεινό θέμα, RTL, 3 μεγέθη γραμμάτων)
js/content.js         όλα τα κείμενα σε 5 γλώσσες
js/content-extra.js   κείμενα καλωσορίσματος, φωνής και βοήθειας (5 γλώσσες)
js/app.js             λογική εφαρμογής
js/config.js          ρυθμίσεις Supabase (προαιρετικά)
sw.js                 λειτουργία χωρίς internet
manifest.webmanifest  εγκατάσταση σαν app
vendor/               qrcode-generator (MIT), jsQR (Apache-2.0)
icons/                εικονίδια
```
